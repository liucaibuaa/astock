# 中国特色情绪分析

## Overview

A股是散户主导、政策敏感、情绪驱动显著的市场。传统DCF/PE估值常常失效，情绪溢价/折价可以长期存在。

核心假设：
- **北向资金**：外资定价权的领先指标
- **板块轮动**：内资结构性偏好的直接反映
- **社交媒体舆情**：散户情绪极端值的捕捉器
- **行为金融学**：解释情绪导致系统性定价偏差的理论框架

⚠️ **执行要求（重要）**

本 Skill 共 5 个分析步骤 + 2 个输出步骤，**必须完整执行到最后（Step 5: 未来 1-5 天股价预测）**，不可中途跳过。股价预测是用户最关心的核心输出。

⚠️ **Prompt 使用指南**

避免使用敏感词："股吧"、"情绪"、"讨论"、"散户"、"性感"、"激情" 等。

正确示例：`请用 chinese-sentiment-analysis skill 分析京泉华`

适用场景：
- 个股短期（1-4周）情绪定价和买卖时机判断
- 判断当前市场情绪位置（恐惧/中性/贪婪）
- 识别情绪极端值带来的交易机会
- 为基本面分析提供情绪维度的修正

## 分析流程

### Step 1: 北向资金分析

**操作**：`load_skill("hk-connect-flow")`

获取数据：
1. 个股北向持仓变化（最近5日、20日、60日）
   - 近5日净流入且60日向上 → 外资看多 (+1)
   - 近5日净流出且60日向下 → 外资看空 (-1)
   - 其他 → 中性 (0)
2. 个股北向持仓占比（占流通股）
   - > 5% → 外资高度控盘
   - 2-5% → 有一定影响力
   - < 2% → 外资关注度低
3. 行业北向资金流向
   - 行业近期持续流入 → 行业β向上
   - 行业流出但个股流入 → 个股α突出

评分输出：`外资情绪评分: +1 / 0 / -1`

---

### Step 2: 板块轮动分析

**操作**：`load_skill("sector-rotation")`

获取数据：
1. 板块动量排名（最近5日、20日收益率排名）
   - 前5 → 强势板块 (+1)
   - 后5 → 弱势板块 (-1)
   - 中间 → 中性 (0)
2. 板块资金流向（主力资金净流入）
   - 持续3日净流入 → 资金建仓
   - 持续3日净流出 → 资金撤退
3. 板块估值分位（PE/PB历史分位）
   - > 80% → 情绪过热
   - < 20% → 情绪过低

评分输出：`板块情绪评分: +1 / 0 / -1`

---

### Step 3: 舆情与行为金融学分析

#### 3A: 板块与产业舆情

**操作**：`load_skill("social-media-intelligence")`

搜索策略：
1. 确定股票所属板块（申万/中信行业分类）
2. 搜索板块龙头动态：如 `"磁性材料 龙头企业 订单"`、`"新能源汽车零部件 出货量"`
3. 搜索产业政策：如 `"新能源汽车 政策 2026"`、`"充电桩 投资"`

**来源过滤（国内A股）**：
- ❌ 排除：`rfi.fr`、`bbc.com`、`voanews.com`、`nytimes.com`、`.onion`
- ✅ 优先：`xueqiu.com`、`eastmoney.com`、`sina.com.cn`、`stcn.com`、`cs.com.cn`、`cninfo.com.cn`

评分输出：`产业情绪评分: +1 / 0 / -1`

#### 3B: 行为金融学诊断

**操作**：`load_skill("behavioral-finance")`

评估维度：
1. **过度反应**：近5日涨跌幅 > 15% → 可能存在过度反应
2. **处置效应**：盈利筹码比例 vs 换手率
   - 盈利 > 90% + 高换手 → 获利盘出逃风险
   - 盈利 < 10% + 低换手 → 套牢盘惜售，抛压轻
3. **锚定效应**：股价是否围绕关键价格（前期高点、定增价）震荡
4. **羊群效应**：同行业个股相关性 > 0.8 → 严重跟风，即将分化

评分输出：`行为偏差评分: +1 / 0 / -1`

### Step 4: 综合情绪评分与价值区间

#### 4A: 综合情绪评分模型

```python
weights = {
    'northbound': 0.25,
    'sector': 0.25,
    'social': 0.25,
    'behavioral': 0.25,
}

sentiment_score = sum(score * weights[dim] for dim, score in scores.items())

if sentiment_score >= 0.5:     sentiment_level = "情绪过热"  # 应降低敞口/回避
elif sentiment_score >= 0.2:    sentiment_level = "偏热"      # 可持有，谨慎追高
elif sentiment_score >= -0.2:   sentiment_level = "中性"      # 按基本面操作
elif sentiment_score >= -0.5:   sentiment_level = "偏冷"      # 可逐步观察
else:                           sentiment_level = "情绪过冷"  # 积极关注/观察
```

## Notes

1. **情绪定价的时效性**：情绪分析有效期通常为 1-4 周，超过这个时间需要重新评估
2. **极端情绪的持续性**：A股市场极端情绪可以持续很久（"非理性繁荣"），不要试图精确抄底逃顶
3. **与基本面结合**：情绪分析应与基本面分析配合使用，情绪只提供"什么时候买/卖"，基本面提供"买什么"
4. **北向资金的局限性**：2023年后北向资金波动加剧，单日大额流入/流出可能受汇率等外部因素影响
5. **社交媒体偏差**：雪球用户以散户为主，观点可能过度悲观或乐观，不代表市场整体
6. **板块轮动的加速**：A股板块轮动周期已缩短至 3-5 天，板块排名需要高频跟踪
